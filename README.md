# 💰 Expense Tracker — Google Workshop

> A beginner-friendly, mobile-first personal finance application designed to help young professionals understand their money, manage expenses, create budgets, and build better saving habits.

---

## 📌 Overview

**Expense Tracker** is a modern personal finance application built for people who are entering the job market and receiving their first salary.

Managing money for the first time can be confusing. Users often struggle with questions like:

- How much should I save?
- How much can I safely spend?
- Where is my salary going?
- How much should I keep for emergencies?
- Am I spending too much?
- How long will it take to reach my savings goal?

This project aims to make personal finance **simple, visual, and beginner-friendly**.

Instead of overwhelming users with complicated financial terminology and dashboards, the application focuses on four simple questions:

> 💵 How much did I receive?  
> 📊 Where is my money going?  
> 🛍️ How much can I safely spend?  
> 🎯 How much should I save?

---

## 🎯 Project Goal

The primary goal of this project is to create a **simple and approachable financial management experience** for young adults who are new to personal finance.

### Core Philosophy

> **"Understand your money before you try to grow it."**

The application focuses on:

- Expense tracking
- Budget management
- Savings goals
- Safe-to-spend estimation
- Financial insights
- Beginner-friendly financial education
